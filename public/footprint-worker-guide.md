# 永久足跡速寫

每個景點永久保留一張專屬圖，重訪另存真實完成時間。抽選確定先由事件通知繪圖，成品私存；只有參觀實際完成才公開。已保存計畫、通知與成品均不等於已參觀，不改寫歷史visit。

唯一作畫流程見 [景點抽選事件指引](footprint-event-worker-guide.md)。先讀hunem_footprint_queue並領取hunem_claim_footprint，只有action=generate才畫；原生收圖、參考照片、透明正方形PNG、目視與租約規則均沿事件指引。重訪沿用原圖；使用者明確授權的替換才走專用維修接口。

不保留晚間批次補位或完成參觀後才啟動作畫的第二套正常流程。23:05只負責日記及代表插圖；訂閱失效時回報需介入，不在晚間自行領取歷史足跡。足跡失敗不能延遲日記截止，也不新增輪詢、舊Cron或本機排程。

保存原PNG及128px JPEG縮圖並核對讀回；未完成參觀的圖維持私有。已有生成原圖時保留同圖重試，不重新作畫。busy／already-drawn或無變化保持安靜，完成收圖或需介入錯誤才回報。
